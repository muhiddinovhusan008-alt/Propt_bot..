Bob 1

1-bob. Algoritm tushunchasi va turlari

Algoritm — qo'yilgan maqsadga erishish yoki masalani yechish uchun bajarilishi lozim bo'lgan buyruqlarning aniq va ketma-ket tartibidir. Algoritm xossalari: aniqlik, tushunarlilik, diskretlik, ommaviylik va natijaviylik.

Algoritmlar 3 turga bo'linadi: Chiziqli (har bir buyruq ketma-ket bajariladi), Tarmoqlanuvchi (shartga qarab u yoki bu yo'nalish tanlanadi) va Takrorlanuvchi (siklik) (buyruqlar bir necha bor takrorlanadi).

Asosiy tushunchalar:

  • Blok-sxemada: Oval — boshlanish/tugash, Parallelogramm — kiritish/chiqarish, To'g'ri to'rtburchak — hisoblash, Romb — shartni tekshirish.
Bob 2

2-bob. Python dasturlash tili asoslari

Python — o'rganish oson, sodda va o'ta qudratli zamonaviy dasturlash tili. Guido van Rossum tomonidan yaratilgan. O'zgaruvchilar ma'lumotlarni xotirada saqlash uchun ishlatiladi.

# Ma'lumot turlari
ism = 'Husan' # str (matn)
yosh = 16 # int (butun son)
baho = 4.8 # float (haqiqiy son)
talabami = True # bool (mantiqiy)
print(f'{ism}ning yoshi {yosh}da')

Asosiy tushunchalar:

  • input() funksiyasi foydalanuvchidan ma'lumot oladi va doimo satr (str) qaytaradi.
  • Son kiritish uchun int(input()) yoki float(input()) ishlatiladi.
Bob 3

3-bob. Shart operatorlari va Sikllar

Shart operatori: if, elif va else orqali dastur turli yo'nalishlarda ishlaydi. Pythonda bloklar probellar (indentation - 4 ta bo'shliq) orqali ajratiladi.

Sikllar: for (aniq takrorlanishlar soni uchun) va while (shart to'g'ri bo'lib turguncha ishlash uchun).

for i in range(1, 6):
    print(f'{i}-qadam: Dasturlashni o'rganamiz!')

Asosiy tushunchalar:

  • Ro'yxatlar (list): mevalar = ['olma', 'anor', 'shaftoli']. Indeks 0 dan boshlanadi.
  • len() funksiyasi elementlar sonini sanaydi.
